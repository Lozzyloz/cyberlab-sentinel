# CyberLab Sentinel


## Web Application Security Assessment & Threat Detection Platform

CyberLab Sentinel is a hands-on cybersecurity project designed to demonstrate
practical web application security assessment, threat detection, and security
reporting using an isolated laboratory environment.

## Project Objectives

- Build an isolated web application security lab.
- Perform authorized security assessments.
- Identify, document, and rate security vulnerabilities.
- Develop Python-based log analysis and threat detection capabilities.
- Test security controls and verify remediation.
- Produce professional security reports and technical documentation.

## Technology Stack

- Kali Linux
- Docker
- OWASP Juice Shop
- Nmap
- OWASP ZAP
- Python
- Git and GitHub

## Project Structure

- `assessment/` — Security assessment activities and findings.
- `detection/` — Python detection tools and rules.
- `docs/` — Technical documentation.
- `evidence/` — Screenshots, logs, and reports.
- `lab/` — Isolated laboratory configuration.
- `scripts/` — Automation scripts.
- `tests/` — Project tests.

## Safety and Authorization

All security testing will be conducted only against applications and systems
owned by the project or explicitly authorized for testing.

The intentionally vulnerable laboratory application will be restricted
to local access.
